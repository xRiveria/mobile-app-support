Journey privacy policy

Operated by xRiveria. Effective 11 October 2026. This policy describes the current release candidate and will be updated if its data practices change.

Records on your device

Journey does not require registration and includes no advertising or analytics SDK. Saved transit locations, commute preferences, history and appearance settings stay in local app storage. Your operating system may include these records in backups according to your settings.

Requests that leave the device

Location access is optional and supports nearby transit and journey guidance. When you search or plan a journey, search text and origin/destination coordinates are sent over HTTPS through the Journey transit service to OneMap. Transit requests such as stop codes, and coordinates for nearby bicycle parking, go to LTA DataMall. These requests are used to provide the feature you selected.

The supplied transit service forwards requests without an application user database or route-history log. Provider authentication tokens stay server-side. Network and hosting providers may process IP addresses and operational request information under their own policies. This is not a claim that every provider immediately deletes all request information.

Maps use the operating system’s map provider. Weather requests use public Singapore data services. Expo supplies app-code updates and may process technical information such as app/runtime version, platform, installation identifiers and network information to deliver compatible updates. App-local saved history is not uploaded for updates.

Choices and retention

Delete individual saved records in Journey. Revoke location/notification access in system Settings. Removing the app can remove its local app storage; backups are controlled by your backup settings and provider. Bus tracking runs while Journey is open and expires after 30 minutes. There is no remote Journey user account to delete.

Support and this website

This support website is hosted by GitHub Pages. GitHub receives technical information about visits under its privacy policy. If you submit a support report, your GitHub username and the information you provide are public and retained with that issue. Avoid submitting sensitive information. Contact xRiveria through the support form for questions about this policy or a request concerning a support report.

GitHub privacy statement

Contact support

Use the GitHub support form to report a problem or ask a question. A GitHub account is required. Include the app version, iOS version and steps to reproduce. Reports are public: do not attach financial records, bank details, home/work addresses, API keys or other private information.
