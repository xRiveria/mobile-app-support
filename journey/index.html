SUPPORT · VERSION 1.0.1

Journey

Singapore bus and MRT information for everyday commutes.

This version is being prepared for release. These pages describe the current release candidate.

Live data and estimates

Check your internet connection and retry if live data is unavailable. Bus arrivals and route information depend on provider availability and operating hours. Times and fares are estimates; confirm service changes with the operator.

Location and alerts

Location is optional. Search manually when permission is denied or you are outside Singapore. Allow notifications and keep Journey open for approaching-bus alerts. Live tracking supports up to three buses and expires after 30 minutes; this release has no continuous background monitoring, widgets or Live Activities.

Saved records

Saved transit locations, preferences and history are stored locally. Delete individual saved records in the app and revoke location/notification access in iOS Settings. Removing the app can remove its local records. Journey does not provide cloud backup of saved journeys.

Journey is an independent app, not an official LTA or SLA product.

Contact support

Use the GitHub support form to report a problem or ask a question. A GitHub account is required. Include the app version, iOS version and steps to reproduce. Reports are public: do not attach financial records, bank details, home/work addresses, API keys or other private information.
