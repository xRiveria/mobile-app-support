SUPPORT · VERSION 1.0.1

Ledger

Keep SGD finance records in two separate local profiles.

This version is being prepared for release. These pages describe the current release candidate.

Getting started

Use the central plus button for an expense or income record. Set category budgets in More > Settings. Subscriptions record their current-month billing occurrence once when the app opens; Ledger does not reconstruct missed past months.

Saving and profiles

If a save warning appears, keep Ledger open and tap Retry. Wait for successful saving before switching profiles. If saved data cannot be read, use Retry loading; Ledger avoids replacing unreadable records with defaults. Profiles are separate workspaces, not password-protected accounts.

Export and deletion

More > Export Data displays entries CSV or profile JSON to copy or share. JSON includes the salary plan. Import/restore is not included. Export records you want to keep before clearing data. Settings clears entries or resets the active profile; the other profile is unaffected. There is no automatic cloud sync, and removing the app can remove local finance records.

Ledger does not connect to banks, make payments, cancel subscriptions or provide investment recommendations. Balances and settlements are manual records.

Contact support

Use the GitHub support form to report a problem or ask a question. A GitHub account is required. Include the app version, iOS version and steps to reproduce. Reports are public: do not attach financial records, bank details, home/work addresses, API keys or other private information.
